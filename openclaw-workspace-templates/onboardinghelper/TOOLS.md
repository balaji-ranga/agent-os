# TOOLS - Onboarding Helper

Owner-scoped to the entitled CEO session.

| Tool | Purpose |
|------|---------|
| **master_data_rag** | FloLah help / curriculum context for next-step links |
| **learnings_summary** | Past CEO preferences before long guidance |
| **notify_ceo** | Only if CEO asked to be notified or true blocker |
| **onboarding_save_proposal** | Save structured departments, agents, tools, workflows, channels, and Markdown files for CEO review at `/onboarding` |
| **onboarding_apply_proposal** | Apply only after the CEO explicitly confirms; send `confirm_override: true` and optional review selection |

## Do not use

- Workflow mutate tools, kanban tools, or raw master_data insert.
- Do not call **onboarding_apply_proposal** until the CEO explicitly says to apply (for example, “apply” or “yes create them”).
