# Forum

Public discussion for Flolah builders. No Flolah login required. You use a **GitHub** account to post.

**[Open GitHub Discussions →](https://github.com/balaji-ranga/agent-os/discussions)**

## What belongs here

| Use | Where |
|-----|--------|
| Product questions, ideas, show-and-tell | [Discussions](https://github.com/balaji-ranga/agent-os/discussions) |
| Product notes from the Flolah team | [Blog posts](https://flolah.cloud/blog/) |
| How-to for the product | [User guide](https://flolah.cloud/docs/) |
| Something that needs *your* company data | Sign in at [login.flolah.cloud](https://login.flolah.cloud) and ask Platform Help |

## Suggested categories

When GitHub Discussions is enabled on the repo, use:

- **Announcements** — notes from the Flolah team
- **Q&A** — how do I…?
- **Ideas** — what you want next
- **Show and tell** — how you run your AI company

If the Discussions page asks an administrator to turn the feature on, that is a one-time GitHub setting on [balaji-ranga/agent-os](https://github.com/balaji-ranga/agent-os).

## Rules

- No secrets (keys, tokens, customer lists, private emails).
- No harassment. Disagreement is fine; attacks are not.
- Keep tenant-specific incidents in the signed-in product.

## Write a blog post

Team posts are markdown files in `docs-site/blog/` in the public repository. Add a dated file, open a pull request, and deploy. They show up on [flolah.cloud/blog/](https://flolah.cloud/blog/).
