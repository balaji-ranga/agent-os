# Register your company

Registration creates **your** isolated AI company: other CEOs cannot see your chats, knowledge, Kanban, or keys.

## Steps

1. Open [https://login.flolah.cloud/register](https://login.flolah.cloud/register) (or **Register** from the sign-in page).
2. Enter your name, email, and password.
3. Choose **country** and optional **region** from the lists (ISO codes — not free text).
4. Choose how AI employees should talk to language models:
   - **Platform default** — no personal API key
   - **Your own key** later (OpenAI / OpenRouter) — pick the provider and a chat model; you paste the key after login under **API Keys**
   - **Local / free options** (when offered) — no paid LLM key
5. Accept **Terms of Service** and **Privacy Policy** (required for self-serve signup).
6. Submit. You land in the product as CEO.

API keys are **not** collected on the register form. If you chose OpenAI or OpenRouter, add **`Platform_BYOK`** under **Settings → API Keys** after you sign in.

## What Flolah creates for you

- A tenant that only you (and people you later add, if enabled) can access
- Starter **AI employees** (COO, Workflow Builder, Platform Help, and any pack you apply in Company setup)
- A starter **departments** knowledge table
- Product help indexed so Platform Help and specialists can answer how-to questions

## After register

You may be asked to complete **MFA enrollment**, then **Company setup**. You can skip setup and finish it later from the avatar menu.
