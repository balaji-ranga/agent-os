# MCP Universe

[MCP Universe](https://flolah.cloud/free-tools/mcp-universe/) is Flolah's free, public directory of Model Context Protocol servers.

Listings are imported from configured authoritative registries or approved community submissions. Each card keeps its source and provenance. Flolah does not infer metadata that a publisher did not provide, and discovery never runs an MCP's advertised tools.

Complete the human check, then search or filter the directory. Open a listing to inspect its publisher, source repository, documentation, transport, authentication declaration, license, version, and available capabilities. Use **Include your MCP** to send a listing for moderation; registering in the official MCP Registry first is preferred.

MCP Universe is a discovery directory. Adding a listing does not connect it to your company. To use an MCP with an AI employee or workflow, review it and configure it separately under **Connectors → MCPs**.
