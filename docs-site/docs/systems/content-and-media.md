# Content and media

## Tools page

**Tools** (`/content-tools`) lists platform tools, test invoke, logs, **Tools → Model**, and **Tools → Rate limits**.

Grant tools per employee on **Workspace → Tools access**.

## Content Explorer

Browse, preview, download, or delete uploads and generated files. Channel media (WhatsApp and similar) appears here after it is mirrored.

## Video content studio

If you applied a **Video content** pack in Company setup, you get a Content Orchestrator and certified graphs:

1. Storyboard and cast (CEO review on Kanban, including portraits)
2. Scene media (short clips)
3. Assembly into a finished file under generated video

Approve CEO-review cards before the pipeline continues. Desktop Chrome may be required for some scene generators.

## Content creator / social

Facebook Page via **Connectors → MCPs**, then operate workflows for publish, comment triage, and a weekly ops rollup in the **bell**.

## Avatars and published scenes

**3D Avatars** and **Published Scenes** let you build a virtual room and share a public guest link. Guest speech uses a room-scoped token; it is not the same as logged-in media playback.

## Speech

When enabled, Agent Chat can use on-platform speech-to-text and text-to-speech (mic and Speak reply). WhatsApp voice notes use the same family of tools.

**Call** on Agent Chat is a live WebRTC session (OpenAI Realtime), not Whisper/Piper. See [Channels](./channels.md).
