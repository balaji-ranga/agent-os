# Onboarding Helper

Path: avatar → **Onboarding** (`/onboarding`), or chat with **Onboarding Helper**.

This is **freeform** org design: you describe departments and AI employees in chat. The helper proposes a plan. You **Review** with checkboxes and **Apply** only what you selected.

Use it **after** (or instead of skipping) [Company setup](./company-setup.md) when you want extra roles that the industry pack did not include.

Tips:

- Name the outcome (“Trading desk with a market watcher who briefs me weekdays at 9”).
- Apply in small batches so you can Resync org docs and grant tools deliberately.
- Workflow Builder can then attach graphs to those new employees.

Onboarding Helper does **not** replace Profile, API Keys, or CRM/ERP enablement.
