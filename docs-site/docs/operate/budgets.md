# Budgets and rate limits

## Department and employee budgets

On **My Org** / Efficiency View you can set:

- Department **purpose** and **monthly token budget**
- Per-employee **token** and **error** budgets (warn, then block)

**Efficiency View** has Org, Department, and **Agent View** (activity, outcomes, **Reset usage** for the month).

Token budgets are not the same as **Tools → Rate limits**.

## Tool API rate limits

**Tools → Rate limits** sets daily/monthly **call** caps for tools that use vendor APIs (on top of token budgets). If a tool stops with a rate-limit message, wait for the window or raise the cap.

## Storage

**Efficiency → Org → Storage (MB)** reflects Knowledge, inbound files, and generated media. Use Content Explorer and data-retention purge on Profile to shrink it.
