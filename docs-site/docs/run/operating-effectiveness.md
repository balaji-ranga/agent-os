# Operating effectiveness

Home can show an **OEI** (operating effectiveness) score from **0–100**. **Green is 75 or above**.

The score is **rules-only** for **your** company (not a model guess). It looks at a short recent window across domains such as vision, org, goals, workflows, autonomy, CRM (when enabled), and governance.

**Goal runs** count how many times scheduled goals actually fired — separate from how many distinct goals you have.

Ask the **COO** to explain the score. Digest dollar figures are a different surface; OEI is the Home operating score.

This is not a billed financial P&L. Company P&L automation is a separate product direction.
