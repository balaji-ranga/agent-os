# Kanban and standups

## Kanban

Path: **Kanban** (`/kanban`).

- Default view: **Weekly**. Switch filters as needed. **All** loads further pages as you scroll.
- **Agent** filter and row checkboxes / **Select all**
- Each card has a **Task ID**. Top-bar search finds it. Links can open `/kanban?task=`
- Open a card for detail, artifacts, and task chat
- CEO-approval cards (for example video cast review) may include a PDF on Artifacts

Tasks appear when the COO delegates, when a goal plan needs recovery, or when you create work yourself.

If **Workspace** says there are no open tasks but Kanban shows cards, refresh `/work` and confirm you are the same account. See [Troubleshooting](../operate/troubleshooting.md).

## Standups

On **My Org**, create a standup, chat with the COO, **Get work from team**, and run a COO summary.

**Get work from team** creates one Kanban card per specialist and rings the bell. That is a visible standup action — not a silent background job.

## Status checker

**Run status checker** (Dashboard) builds an HTML report: cards waiting on you, failed cards with reasons, recent completions. The same kind of report can be posted to standup and emailed on a platform schedule.
