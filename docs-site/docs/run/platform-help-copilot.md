# Platform Help copilot

Open the floating **Platform Help** button in Flolah. It can explain product features and help prepare supported settings. Use Workflow Builder to create or change a workflow graph.

## Describe the result you need

Open **Copilot options** (⋯) to choose **Prepare setup and guide me**, **Guide me step by step**, or **Prepare fields for my review**. Describe the task in the normal chat composer. Copilot uses the authorized screen map, relevant reviewed lessons and fresh visible controls. Dynamic choices must be inspected on the actual screen; unavailable or ambiguous controls need clarification or manual guidance.

Select **Review setup** to inspect a proposed change. Review the fields at the bottom of the panel, then use **Approve and apply fields** or **Approve and fill next field**. You can cancel the review. Applying values does not prove that the application saved them. Use the normal form's Save control and check the saved result. Embedded applications may autosave; creating a record requires its separate creation approval.

Errors appear beside the composer and can be dismissed. Failed requests remain available to retry. If the page, options or existing values changed, request a fresh review. Copilot preserves newer edits rather than silently overwriting them. Enter credentials and complete login yourself through the normal product flow.

## Teach a reusable lesson

Under Copilot options, open **Teach Copilot**. Name the lesson, describe its purpose, when to use it and expected outcome, then demonstrate and capture each screen step. Record a checkable success condition. The recorder stores structural guidance and your descriptions, not field values or credentials. Review before publishing; descriptions must not contain private transaction data.

Published lessons are private to the current company and human login. **Replay recording** offers ordered steps with pause/resume/stop, fresh inspection and your confirmation. It does not replay stored values or automatically save records. The source-built platform map, source-managed starter recipes and your private learned map are separate; none certifies every conditional screen state.

## Different copilot surfaces

Platform Help assists inside the signed-in Flolah product. [Digital Adoption website copilots](../systems/digital-adoption.md) assist visitors on separately registered websites. Their visitor tasks, website knowledge and workflow authorization are separate. [Copilot connector nodes](../systems/copilot-workflows.md) send governed instructions to authorized website panels; a website target group is not a Platform Help chat session.
