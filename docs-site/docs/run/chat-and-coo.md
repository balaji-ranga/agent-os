# Chat with the COO

Home (`/`) opens chat with the **COO**. Use **Chat with** to switch employees. **My Org** holds the org chart and standups.

## Send work

1. State the **outcome** in one message when you can.
2. Attach files with the **paperclip** (documents, images, audio, video). Attachments go to Knowledge and inbound files.
3. Replies render markdown. Generated images, audio, and video play **inline while you are logged in**.
4. Small **tool icons** under a reply show what the employee used (knowledge search, email, notify, browser, and so on).

**History** and **Browser session** side panes start closed. Use the icons next to **New chat**. **New chat** archives the current thread.

Optional **mic** and **Speak reply** appear when speech is enabled for your environment. **Call** starts a live browser session when that employee has Voice / OpenAI Realtime.

## How the COO delegates

Clear specialty asks (“research X”, “draft a social post”) are handed to the matching employee with full context. Vague “help me” may stay with the COO.

The COO creates **Kanban** cards for specialty work. Watch the board and the **bell** when something needs you.

COO-native asks (list workflows, standups, tools, Kanban) usually stay with the COO.

If you want a specialist to **reach you**, say so (“have Research contact me”). That employee rings the bell with a link to **their** chat. Ordinary live replies should not spam the bell — ask them to **notify you** when async work finishes.

## WhatsApp and Slack

Configure **Channels** on the employee. Replies start with the employee name. See [Channels](../systems/channels.md).

## Platform Help

For how-to, switch to **Platform Help**. It answers from product docs first. It may suggest the COO or Workflow Builder for live data or graph edits, but it should not bounce you with only “talk to X”.
