# Notifications and Digest

## Bell

The top-bar **bell** lists platform alerts and employee messages that were pushed to you.

- Hover a short snippet to read the full title or body
- Open the linked chat or Kanban card
- **Clear** / dismiss items you have handled

Ask employees to notify you when async work should ping the bell. Live chat replies should not.

## Digest

**Digest** (`/this-week`) is the weekly company pulse: AI workers, tasks, time saved, estimated value, and the last **goal plans** with timestamps. **View all** opens **Goal plans**.

Digest is not the same as Home **operating effectiveness** (a 0–100 score). See [Operating effectiveness](./operating-effectiveness.md).

## Goal plans

Durable multi-step work (for example CRM then ERP) appears as goal plans. Digest shows a couple of recent ones; `/goal-plans` lists the week. Each new scheduled fire in plan mode starts a **new** run rather than reusing yesterday’s.
