# Navigation

## Top bar

- **Sidebar toggle** — collapse to icons
- **Bell** — notifications from employees and the platform
- **Search (Ctrl+K)** — chats, employees, workflows, knowledge, **Kanban task id**, **workflow run id**
- **Profile menu** — setup, onboarding, appearance, this user guide, Video Tours, Platform Help chat, logout
- **Theme** — sun/moon for Day ↔ Night

Left-nav **sections** (Settings, Run & Operate, and so on) start **collapsed**. Expand the ones you use; the browser remembers.

## Home and workspace

| Label | Use for |
|-------|---------|
| **Home** | Executive chat (COO by default). On phones, **Chat** opens a full-screen sheet. Home may show an **operating effectiveness** score. |
| **Digest** | Weekly pulse: work, time saved, recent **goal plans** |
| **Workspace** | Daily board: open Kanban tasks, team, activity |

## Run & Operate (typical)

My Org, Kanban, Scheduled goals, Goal plans, Broadcast, Knowledge, Content Explorer, Policies, Browser Session, Efficiency View, CRM/ERP (when enabled), Avatars.

## Company Tools

Workflows, AI Employees, Tools, Connectors, MCP, AgentExchange.

## Settings

API Keys, IP allowlists, Tokens, Workspace Builder, Menu visibility.

**Menu visibility** only hides labels in *your* sidebar. It is not a security control.

Timezone for boards and workspace: **Profile → Display timezone**.
