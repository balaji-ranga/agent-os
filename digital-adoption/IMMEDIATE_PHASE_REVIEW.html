Safe execution

Bounded recovery for known validation errors. Fresh observations after dependent fields. Persistent action guards prevent duplicate dispatch across retries and coordinator restart.

Unknown Save outcome: stop and reconcile. A timeout cannot prove failure; never blindly click again.

Clear visitor UX

Typed Apply / Edit / Reject reviews. Editing creates a newly validated proposal; old approval cannot apply it. Show the current stage, elapsed time and a usable Stop control.

Keep specific errors visible until resolved. Explain panel authorization, workflow link, peer pairing and task state separately.

Fresh-owner journey

  1. Sign in and register through the product UI.
  2. Complete real DNS proof and normal platform approval.
  3. Install the snippet; confirm actual initialization and diagnose origin/CSP issues.
  4. Discover approved routes, forms, fields and navigation; make coverage gaps visible.
  5. Teach a parameterized task, check compatibility, then run a real task test.
  6. Publish through owner review; prove a fresh visitor can replay with different values.
Compatibility is not successful replay. Existing recipe validation checks map keys and versions. Tested-ready requires an actual task run and its declared outcome evidence.

Use one resumable readiness checklist in the existing owner workspace. Keep normal DNS and approval gates; no developer database seeds or hidden imports may close onboarding acceptance.

Delivery and release gates

  1. Outcome contracts, typed failures, correlation and fault harness.
  2. Shared controller, dependency handling, attempt fencing and optional host proof.
  3. Editable visitor reviews, truthful progress and connection states.
  4. Owner checklist, diagnostics and separate compatibility / task-test evidence.
  5. Fresh-owner proof, scoped two-site acceptance and real workload measurement.

Require 10 valid journeys with three fresh-value repetitions each, zero unintended submissions or duplicate writes in fault tests, and independently verified local Customer → Note → Opportunity results.

Public flolah.cloud testing has no login or public form submission. The loopback host supplies synthetic Save tests. Keep Action Policies and the approved 24-hour private-index retention policy.

Defer automatic recipe repair, advanced campaigns/analytics, broad integrations and multi-coordinator HA. Previously deferred real Safari/iOS, Android and full screen-reader certification remain explicit.
