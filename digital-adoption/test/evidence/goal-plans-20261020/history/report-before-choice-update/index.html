How to test

  1. Open the local Customer page and its copilot. Choose Plan a task in Chat, with Assist enabled.
  2. Send a complete goal, review the proposed steps, then select Start reviewed plan.
  3. Review/edit/reject each field change; approve navigation and confirm every Save separately.
  4. For missing facts, reply in the same Goal-plan chat. Review the revised plan before execution.

Limits and recommendations

  • Use Plan a task, review the outline, start it, and approve each effect/Save separately.
  • Keep target browser tabs open and authorized. This feature grants no autonomous workflow authority.
  • Inspect host state after unknown outcomes; do not replay uncertain writes.
  • Retain broader Phase 1/2 limitations and provider stability monitoring. A final passing run is not a guarantee of all model responses.

Plans contain up to 12 steps, four default planning attempts per step, eight clarification rounds, a 128 KiB context cap and 24-hour maximum retention. They remain private to website/session/conversation and current authorization. Pause/cancel/access changes invalidate further dispatch. Plans can survive an authorized panel reload or backend restart; a new visitor session does not automatically inherit old authorization. No knowledge seeding or new autonomous grant was used in live tests.

Broader Phase 1/2 remains 14 Passed / 16 Partial / 2 Deferred from its existing ledger. This scoped feature release does not certify those outstanding branches. Native Safari/iOS/Android and full screen-reader matrix remain user-deferred.
