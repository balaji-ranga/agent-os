What changed

  • Narration-only action responses fail the structured contract. A coordinated request is routed, using its original full text, to the real Goal planner.
  • Ordinary buttons receive separate fresh activation references. Read-only highlight references cannot click, and native Save retains its dedicated path.
  • The checker judges routing separately from actual steps. Reviewed step scope is preserved rather than overridden by incidental read-only words in its constraints.
  • Observation context retains required facts while deduplicating identical reference metadata within the existing 30,000-byte request cap. A required-context overflow reports a specific context-limit error.
  • Empty search results and host errors are distinct. A recorded activation is never repeated within the same step.
  • Search topic interpretation, page-title responses and continuity guidance use page/conversation context with no website-specific core rules.

The historical D run exposed result-assessment/replay problems.
