## Voice script (draft)

After register and login, open your user menu. Profile is home for security and preferences. API Keys holds BYOK providers and your chat model. Later, Onboarding in this same menu will capture purpose, vision, and goals — and warn before overriding an existing org. If you skip Onboarding, FloLah still gives a lean starter pack: COO, Workflow Builder, and Platform Help.

## Shot list

1. User menu
2. Profile
3. API Keys
4. Mention Onboarding item (or placeholder)
5. Dashboard return
