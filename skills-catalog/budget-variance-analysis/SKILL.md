# Budget Variance Analysis

1. Confirm period, version, currency and cost-center mapping for budget and actuals.
2. Reconcile totals before calculating absolute and percentage variances; handle zero budgets explicitly.
3. Separate timing, volume, price and one-off effects only where evidence supports them.
4. Report material variances, owners, assumptions and next checks. Never change budgets or book adjustments during analysis.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
