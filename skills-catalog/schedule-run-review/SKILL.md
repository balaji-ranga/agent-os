# Schedule Run Review

1. List schedules in the company context and record timezone, cadence, status and intended outcomes.
2. Correlate recent runs with actual work-history evidence. Distinguish disabled, missed, queued, failed and completed runs.
3. Identify duplicate schedules, stale evidence and dependency failures without restarting anything.
4. Report actionable exceptions and the authorized owner. Never create a replacement schedule or change notification policy during a status review.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
