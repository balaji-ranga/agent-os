# Sales Pipeline Review

1. Find the permitted CRM read action and obtain the requested period's opportunities.
2. Check stage definitions, currency, close dates, owner, last activity and duplicate opportunities.
3. Calculate weighted/unweighted views using the company's stated probabilities; identify stale and slipped deals.
4. Explain risks and proposed owner actions. Do not change stages, probabilities, records or commitments during a review.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
