# Proposal Drafting

1. Read the customer's requirements, approved offering and commercial policy.
2. Structure objectives, deliverables, exclusions, milestones, responsibilities and acceptance criteria.
3. Include only verified prices and approved terms; mark legal, tax and unsupported capability claims for review.
4. Return a clearly labeled draft with sources and unresolved approvals. Do not send, sign or commit the company.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
