# Knowledge Base Curation

1. Read relevant approved articles and recent issue evidence.
2. Identify outdated statements, contradictions, duplicate pages and missing prerequisites.
3. Draft narrowly scoped corrections with source references, tested steps where available, and ownership.
4. Preserve approved policy and do not publish changes automatically. Highlight claims requiring subject-matter review.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
