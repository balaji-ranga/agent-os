# Incident Triage

1. Establish incident time, impact and available telemetry through granted read tools or supplied logs.
2. Create a timestamped observation timeline and separate symptoms from possible causes.
3. Identify affected owners, immediate containment options and safe diagnostic checks. Never expose secrets from logs.
4. Report evidence, uncertainty and proposed actions. Restart, configuration change and destructive containment need explicit authority; this skill is not an autonomous remediation grant.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
