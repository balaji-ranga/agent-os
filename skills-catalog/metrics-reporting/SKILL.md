# Metrics Reporting

1. Confirm metric definitions, denominator, period, timezone and authoritative source.
2. Reconcile inputs and calculate values with explicit treatment of missing records and zero denominators.
3. Compare like-for-like periods, distinguishing observations from causal explanations.
4. Return a concise metric brief with source dates, uncertainty and next checks. Do not redefine targets or claim stale snapshots are current.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
