# Audit Evidence Pack

1. Read the audit scope, control list and evidence period.
2. Map each control to approved source documents, timestamps and responsible owners.
3. Mark evidence as present, partial, stale or missing; distinguish a documented control from proof it operated.
4. Prepare an index and gap list without altering evidence or exposing other companies' records. Never claim formal audit assurance from an automated checklist.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
