# COO Operating Review

1. Query active company objectives and list owner-scoped goal runs. Match initiatives, goals and evidence IDs; do not attach unrelated work to an objective merely because the agent is COO.
2. Separate completed outputs, work in progress, blocked steps and unverified agent claims. Compare last update timestamps and accountable owners.
3. Rank blockers by business impact, deadline and dependency, identifying the smallest authorized next action. Do not change goals, budgets, schedules or tools during a review.
4. Deliver an executive brief with objective progress, evidence, owner/action/deadline and explicit unknowns. If asked to implement a follow-up, preserve the existing routing/planning and approval controls.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
