# Connector Context Research

1. Extract the requested subject, freshness, geography and output from the user's context; distinguish read research from send/update actions.
2. Search connector actions by semantic intent. Check connected services, granted actions and action guidance before selecting a canonical service.operation.
3. Execute only an appropriate permitted read action with its documented parameters. If several sources are relevant, combine their evidence without claiming unsupported capabilities.
4. Cite source links and timestamps, deduplicate results and report unavailable connectors or empty results honestly. Do not install connectors or change credentials. A selected tool narrows the method, not the user's authority.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
