# Objective Progress Review

1. Query the requested objective and key results in the current company context.
2. Read targets, units, deadlines and linked initiatives. Keep different units separate and do not turn activity counts into achieved outcomes.
3. Identify verified current values, change since the comparison period, missing measurements and source dates.
4. Report on-track/at-risk only with stated calculation and assumptions. Recommend a measurement or owner follow-up; do not edit key results without a separate request.

## Operating boundaries

Use only current company/owner-scoped evidence and granted capabilities. Skills do not grant tools, credentials or approval. If a prerequisite is unavailable, report it exactly; never fabricate a tool result or bypass existing routing, planning, action-control or tenant isolation. Finish with evidence references, assumptions and the smallest authorized next step.
