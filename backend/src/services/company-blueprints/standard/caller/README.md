# Caller wrap-up (Slow / Realtime Caller)

Golden graph for Workflow Builder to clone. Chat phrase: **run caller wrap up**.

Bind the agent node to your hired Caller employee (`template_base_id` `slow-caller` or `realtime-caller`). The graph does not assume a display name. Input is the conversation transcript (platform hangup wrap-up or CEO paste).

Not a telephony stack. Durable follow-up still uses **goal plans** (`agent_goal_*`).
