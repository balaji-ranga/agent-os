Flolah Browser Chrome Extension
===============================

1. Open chrome://extensions and enable Developer mode.
2. Choose Load unpacked and select this folder.
3. In Flolah, open Browser Session and create an extension pairing code.
4. Open the extension, enter the Flolah login address and pairing code.
5. On a tab you want Flolah to use, click Allow Flolah on this tab.

The extension controls only tabs you explicitly allow. Pause or Stop all detaches immediately.
Never share pairing codes or copy extension storage. Revoke the device from Flolah if lost.
